Το προγραμμα σε περιπτωση σφαλματος εκτυπωνει μεχρι τη γραμμη σφαλματος και σε επιτυχυ αναλυση εκτυπωνεται ολο το προγραμμα. Τυποι δεδομενων ειναι integers μεταβλητες load και μεταβλητες varchar(αλφαρηθμιτικα) ακολουθα αυστηρα την σειρα SELECT -> FROAM -> WHERE -> GROUP BY -> ORDER BY -> LIMIT διαφορετικα υπαρχει συντακτικο σφαλμα. Η αρνητικοι αριθμοι δεν αντιμετωπιζονται ως μοναδαιοι αρνητικοι τελεστες.
